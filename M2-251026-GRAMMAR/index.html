Real or imaginary?

Two versions of the same sentence

If it will rain tomorrow, we will stay home.

If it rains tomorrow, we will stay home.

The if-clause goes back one step

if-clause

rains
rained

result clause

will
would

If it rained tomorrow, we would stay home.

What each one is for

real

If it rains tomorrow, we will stay home.

It can happen, so we plan for it.

imaginary

If it rained tomorrow, we would stay home.

It could happen too, but we are imagining, not planning.

The past form in the if-clause is what tells you it is not real.

The two forms

if-clause

result clause

Real

if + present

will + verb

Imaginary

if + past

would + verb

The if-clause never takes will. If the if-clause comes first, put a comma after it.

Keep the chain going

The chain

  1. I give the if-clause.
  2. You finish it.
  3. The next person starts with your result clause as their if-clause.
  4. Round one is real. Round two is imaginary.

real

If I pass my exams, I'll go to college.

If I go to college, I'll study design.

imaginary

If I had ten million baht, I'd buy a house.
